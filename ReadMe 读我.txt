目前人物更新说明：
人物目前版本为0.20，期间的0.19因为没有完成更新，所以统一到这次0.20一起更新。
0.20主要更新了对人物三气及以下技能的优化和重制，AI的修改并且对人物基础强度进行了一定的调整。
人物重新区分不同的mugen版本，WIN版本最高强度为论外最上，攻击防御均进行了提升。
人物检测绑定觉醒开关，这是为了削弱觉醒前的强度，方便对战。
0.20增加了一些技能，并对一些技能进行的修改重制，部分技能的BUG和特效问题也进行了修复。
总体来说，0.20版本是对冥界草觉醒前后的强度进行更大的区分，上限提高并保证下限，
新增的部分技能如果测试过于强大则会进行相应的削弱。
人物强度至少为准神，且对战相性差，请自己判断是否合适与其他人物对战。
萘塞尔人物本体强度未觉醒为准神，浮屠模式下虽仍为准神但更为暴躁，觉醒为神下，浩劫启动后为论外，防御面为论外，攻击面也为论外。

浮屠模式：这是为了展示冥界草不留手的情况下的实力，冥界草在该模式下AI将不再受限制，血量会随着
时间自动削减，但会有一个限值。浮屠模式下冥界草将会进入浩劫并使用冥界审判，是否使用超即死依旧由觉醒决定。
浮屠模式会强制关闭普通模式AI并开启浮屠AI进行对战。若要手操请关闭浮屠模式和普通模式两个开关。

生命设定：在生命高于最大生命值的15%是会以一地速度自己削血，此过程不受敌削血，低于15%则停止自我削血
且需要受到敌方削血才可击破。
AI设定：连段无限制，技能连段无保护。
技能强化设定：冥·魂式和冥·十噁增强为超即死技能。
超即死设定：是否使用其余四至五气超即死依旧由觉醒决定。
检测设定： 检测到敌方使用混线，则强制觉醒，且无视觉醒开关。
浩劫设定：在血量低于15%后，冥界草有一定的概率直接跳过觉醒并开启浩劫。
